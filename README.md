# CHILL ZONE

Сайт игрового пространства CHILL ZONE (Хасавюрт): 3D-комната, онлайн-бронирование, оплата переводом с проверкой чека, админ-панель `/admin/login`.

- Фронтенд: статический сайт (HTML/CSS/JS без сборки), хостинг Vercel.
- База данных и серверная логика: Supabase (PostgreSQL). Все таблицы закрыты RLS, доступ только через функции в `supabase/functions.sql`.
- Подключение: `config.js` (публичный URL проекта и публичный ключ Supabase).
- Защита от двойного бронирования: ограничение `EXCLUDE USING gist` в таблице `booking_slots`.
- Пароль администратора хранится только как bcrypt-хеш в базе; в репозитории его нет.
